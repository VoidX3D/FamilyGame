# Code of Conduct

## The short version

Be kind. The game is for families, and it should be safe for the youngest
person in the room.

## What is expected

- Treat everyone in the room, and everyone in the project, with respect.
- Keep the content family friendly.
- Accept that people make mistakes, and help them fix it.
- Take a disagreement to the disagreement, not to the person.

## What is not acceptable

- Harassment, insults, or anything that targets someone.
- Sexual content, or content that sexualises a minor.
- Hate speech of any kind.
- Deliberately sharing anyone's private information.
- Using the service to run a public game room, or to collect other
  people's data.

## Reporting

If something happens in a game or in an issue, tell the host of the room
or open an issue. Reports about the project itself can go to the
maintainer privately, the same way as a
[security problem](SECURITY.md).

## Enforcement

The maintainer decides what to do about a problem, and will usually start
with a conversation. If the behaviour continues, the room, the issue or
the account may be blocked.
