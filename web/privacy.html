Privacy Policy

Last updated: 20 October 2026

The Family Game Hub is a private game that you run for your own family. This policy explains what the service does with the little data it handles. The short version: it keeps as little as possible, for as short as possible, and shares none of it.

What is stored

  • Your display name, so the other players know who is in the room. It is held in the room's memory while the room is open, and it is gone when the room closes.
  • A seat token in your own browser, so a refresh or a dropped connection puts you back in your seat rather than making you start again.
  • The host passcode is never stored. It is compared against the value on the server, and only an opaque session token is given back.
  • The content you edit in the host console, if you choose to save it. It stays on the machine running the server.

What is not stored

  • No email address, no password, no profile, no avatar.
  • No advertising, no analytics, no third party trackers.
  • No chat. Nothing you say in the room is written down.
  • No location, no contacts, no camera, no microphone.

Who can see what

The secret parts of a game stay on the server. The impostor's word, the hidden person, the current prompt: these are never sent to the other players, and they only appear once the game reveals them. The host can see the host-only notes for the game they are running. Nobody else can see anything.

How long it is kept

Rooms live in the memory of the server and are cleaned up automatically. A room that nobody is connected to is removed after thirty minutes of being idle. The content file is kept until you replace it or reset it.

The server

The game server is hosted by a private host. The front end is served as static files. Neither runs advertising, and neither shares anything with a third party.

Children

This is a family game, and it is suitable for children. Because there are no accounts and no personal data, there is nothing to collect and nothing to delete. A parent or guardian runs the host console and the room.

Your rights

Because the server holds so little, there is very little to ask for. If you want a room's data gone before the half hour is up, the host can press New room, which destroys the old room and its players immediately. To remove the saved content altogether, use Reset collection or Reset all in the host console.
