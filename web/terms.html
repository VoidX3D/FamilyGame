Terms of Use

Last updated: 20 October 2026

The Family Game Hub is a private party game. By using it, you agree to the handful of rules below. They are deliberately short.

1. It is for your family

The service is meant to be run by one host for a small group of people who know each other. Do not use it to run a public service, to collect other people's data, or to harass anyone.

2. Behave

The games are for fun. Keep the content family friendly. Do not draw, write or say anything that is hateful, sexual, or aimed at hurting someone in the room.

3. The host is responsible

Whoever holds the passcode can start games, edit the content and remove players from the room. Share the passcode with the family, not with the internet.

4. No warranty

The service is provided as it is, without any promise that it will always be up. Rooms live in memory, so a server restart empties them. Keep that in mind before a big family game night.

5. Your content

The words, questions and people in the content bank are yours to change. Resetting a collection puts the built-in list back. You are responsible for what you put in, and for keeping it suitable for whoever is playing.

6. Ending it

The host can destroy a room at any time with New room. Anyone can leave at any time with Leave this room.

7. The fine print

These terms are not a contract with a company, and the service is run as a project rather than a business. If something goes wrong, the project is open source and you can host your own copy. See the readme for how.
